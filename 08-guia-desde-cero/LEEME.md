# Guía paso a paso: Sistema de Reserva de Laboratorios desde cero

1. Abre **GUIA-1-FLASK.html** (Python) o **GUIA-2-EXPRESS.html** (Node) en el navegador. Tiene índice lateral y botón "Copiar" en cada bloque de código. Los `.md` tienen el mismo contenido para verlos en VS Code con `Ctrl+Shift+V`.
2. Crea tu proyecto en otra carpeta y sigue los pasos en orden. Cada paso termina con "✅ Verifica" y "💾 Commit".
3. **solucionario/** tiene los dos proyectos terminados (14 pruebas cada uno). Úsalo solo para comparar cuando algo no te funcione.

Ejecutar el solucionario:
- Flask: `cd solucionario/reservas-flask` → `python -m venv venv` → `venv\Scripts\activate` → `pip install -r requirements.txt` → `python app.py`
- Express: `cd solucionario/reservas-express` → `npm install` → `npm run dev`

Recomendación para hoy: haz la guía de tu lenguaje más fuerte. Primero **escribe** el código tú, sin copiar y pegar todo, al menos en los pasos 4, 6 y 7 (validaciones, CRUD y reservas), que es lo que más se parece a lo que te van a evaluar.
